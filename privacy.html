プライバシーポリシー

第1条（適用範囲）

QNAUDIO（以下、「当方」といいます。）は、当方が提供するWebオーディオプレイヤーサービス「QNPLAYER」（PLAYER、QNVIDEO、QNTUNER、QNPITCH を含みます。以下、「本サービス」といいます。）における、ユーザーの情報の取扱いについて、本プライバシーポリシー（以下、「本ポリシー」といいます。）を定めます。

当方は、個人情報の保護に関する法律その他の関係法令を遵守します。

第2条（取得する情報）

当方は、本サービスの提供にあたり、次の情報を取得または保存します。

1. アカウント情報

Googleアカウントでログインしたとき、認証サービス（Firebase Authentication）を通じて、Googleアカウントの識別子（UID）、メールアドレス、表示名、プロフィール画像のURLを取得します。表示名とプロフィール画像は、画面上のログイン表示に使います。

2. プランと購入に関する情報

プランの種類、有効期限、購入日時、解約予定かどうかを、UIDに紐づけてデータベース（Cloud Firestore）に保存します。クレジットカード番号などの決済情報は、決済サービス（Stripe）が取得・管理し、当方は取得しません。

3. 同期データ

同期機能（現在は一部のアカウントで先行提供）を使うと、次の情報をアカウントに紐づけて保存します。

  • 曲名、アーティスト名、ON/OFF、お気に入り、フォルダ、並び順
  • マーカー（位置・メモ・色）、A-B ループの位置、テキストメモ
  • QNVIDEO に保存した動画のURLと、ユーザーが入力したタイトル、マーカー、A-B 点
  • 曲の同一判定に使う識別子（ファイル名とファイルサイズから作る値）

音声ファイル本体、再生位置、アプリの設定（音量・テーマなど）は、同期されません。

4. 端末内に保存される情報

読み込んだ音声ファイル、Library、マーカー、設定などは、ユーザーの端末のブラウザ内（IndexedDB、localStorage）に保存されます。これらは当方のサーバーには送信されません。ブラウザのデータを消去すると失われます。

5. 転送（Transfer）機能の情報

端末どうしで音声ファイルを送受信する機能です。音声ファイルは、ブラウザの通信機能（WebRTC）で端末間を直接送られ、当方のサーバーを通らず、保存もされません。接続のために、一時的なコードと接続情報をデータベースに書き込みます。これらは接続が完了するとすぐに削除し、接続されなかった場合も5分で無効になります。接続の仕組み上、通信相手の端末には、ユーザーのIPアドレスが伝わることがあります。

6. お問い合わせの情報

お問い合わせをいただいたときの、メールアドレスと内容です。

7. アクセスに関する情報

本サービスを配信するサーバーや、利用する外部サービスには、IPアドレス、ブラウザの種類などのアクセス記録が残ることがあります。

第3条（利用目的）

当方は、取得した情報を次の目的で利用します。

  • 本サービスの提供・運営のため（ログイン、プランの判定、同期、転送を含みます）
  • 料金のお支払い、契約の更新・解約の手続きのため
  • ユーザーからのお問い合わせに回答するため（本人確認を行うことを含みます）
  • メンテナンス、重要なお知らせなど必要に応じたご連絡のため
  • 不具合の調査と、サービスの改善のため
  • 利用規約に違反したユーザーや、不正・不当な目的でサービスを利用しようとするユーザーを特定し、ご利用をお断りするため

第4条（外部サービスの利用と情報の送信）

本サービスは、次の外部サービスを利用します。利用にあたり、ユーザーの情報がそれぞれの事業者に送信されることがあります。

Google（Firebase、Google Fonts ほか）

ログイン認証（Firebase Authentication）、データの保存（Cloud Firestore）、解約手続きの処理（Cloud Functions）、フォントの配信（Google Fonts）、転送機能の接続補助（STUNサーバー）に使います。Googleによる情報の取扱いは、Googleプライバシーポリシーに従います。

Stripe（決済）

有料プランのお支払いと、解約手続き（カスタマーポータル）に使います。決済の際、ユーザーを識別するためにUIDをStripeに渡します。Stripeによる情報の取扱いは、Stripeのプライバシーポリシーに従います。

YouTube API Services（QNVIDEO）

QNVIDEO は、YouTube API Services（埋め込みプレイヤー、動画タイトルの取得、再生リストの取得）を利用します。QNVIDEO を使うことで、ユーザーは YouTube利用規約 に同意したものとみなされます。YouTubeの埋め込みプレイヤーや、サムネイル画像の表示にあたり、YouTube（Google）が、Cookieなどでユーザーの情報を取得することがあります。取扱いは Googleプライバシーポリシー に従います。

  • 当方は、YouTubeの映像・音声をダウンロード、保存、加工しません。
  • 当方が保存するのは、動画のURL、ユーザーが入力したタイトル、マーカーなどの、ユーザーが作成した情報です。YouTubeから取得したタイトルは、ユーザーの端末に最大28日間だけ一時保存します。
  • 再生リストの取得では、ユーザーが操作したときに限り、Googleの確認画面を表示して、YouTube の読み取り権限（youtube.readonly）を求めます。取得したアクセストークンはメモリ上でのみ使い、保存しません。取得した再生リストの情報も保存しません。ユーザーが Library に追加した動画のURLなどだけが保存されます。
  • ユーザーは、Googleのセキュリティ設定ページから、いつでも当方のアクセス権限を取り消せます。

当方による、Google APIから受け取った情報の使用および他のアプリへの転送は、限定的な使用の要件を含む、Google API Services User Data Policy に準拠します。

広告配信サービス

現在、本サービスは広告配信サービスを使用していません。今後、広告の表示（動画広告の視聴による機能の一時解放を含みます）のために広告配信サービスを導入する場合は、Cookieなどの識別情報が、広告事業者に送信されることがあります。導入するときは、事前に本ポリシーを改定し、利用する事業者と、無効にする方法をお知らせします。

第5条（Cookie・ローカルストレージ等の利用）

本サービスは、ログイン状態の保持、設定やデータの端末内への保存のために、ブラウザの保存領域（Cookie、localStorage、IndexedDB）を使います。これらは、サービスの動作に必要なものです。ブラウザの設定で削除、または無効にできますが、その場合、ログイン状態や保存したデータが失われたり、一部の機能が使えなくなったりすることがあります。

現在、本サービスはアクセス解析ツールを使用していません。導入する場合は、第4条の広告配信サービスと同様に、事前に本ポリシーを改定してお知らせします。

1. 当方は、次に掲げる場合を除いて、あらかじめユーザーの同意を得ることなく、第三者に個人情報を提供することはありません。

  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき

2. 第4条の外部サービスへの情報の送信は、本サービスの提供に必要な範囲で行うものであり、本条の第三者提供には当たりません（利用目的の達成に必要な範囲での業務の委託にあたります）。

第7条（保存期間と削除）

1. アカウント情報、プランに関する情報、同期データは、ユーザーが本サービスを利用している間、保存します。

2. Library から曲や動画を削除すると、同期されている情報も削除されます。ほかの端末にある音声ファイルは削除されません。同期の削除記録は、端末間で削除を伝えるために、一定期間（最長180日程度）保存することがあります。

3. アカウントに紐づく情報の削除をご希望の場合は、第10条の窓口にご連絡ください。本人確認のうえ、合理的な期間内に対応します。ただし、法令により保存が必要な情報や、決済事業者が保存する情報は、この限りではありません。

4. 端末内に保存されたデータは、ログアウトしても消えません。ユーザー自身で、ブラウザの設定などから削除してください。

第8条（安全管理）

当方は、取得した情報の漏えい、滅失、毀損を防ぐため、通信の暗号化（HTTPS）と、データベースのアクセス制御（アカウント本人だけが自分のデータを読み書きできる設定）などの、合理的な安全管理措置を講じます。ただし、インターネット上の通信やサービスの安全性を、完全に保証するものではありません。
